A fix release for Markdown search.

## Fixed

- Markdown files that keep old headings as HTML anchors, such as `<a id="old-heading"></a>`, no longer produce empty search results. A block made only of HTML markup is now left out of the index; code and ordinary text are unchanged.

After upgrading, the next `pecia index` rechunks every Markdown file and rebuilds its embeddings once. Other file types are not affected.

## Upgrade

| System | Command |
| --- | --- |
| Homebrew | `brew upgrade pecia` |
| Scoop | `scoop update pecia` |

New installs follow [Installing Pecia](https://github.com/eyuppastirmaci/pecia/blob/v0.1.1/docs/install.md).
