Pecia's first release: a local command-line tool that indexes a folder of documents and source code into one SQLite file and searches it by words (BM25), by meaning (a small embedding model running on your computer), or both. Everything runs offline; the model is downloaded once, on the first semantic run.

## Install

No Java installation is needed: each package bundles its own runtime.

| System | Install |
| --- | --- |
| macOS (Apple silicon), Linux (x64, arm64) | `brew install eyuppastirmaci/pecia/pecia` |
| Windows (x64) | `scoop bucket add pecia https://github.com/eyuppastirmaci/scoop-pecia`, then `scoop install pecia` |

The archives below can also be installed by hand; each has a `.sha256` file to check it against. [Installing Pecia](https://github.com/eyuppastirmaci/pecia/blob/v0.1.0/docs/install.md) covers every way, and the security prompts of unsigned downloads.

## Get started

```
pecia init
pecia index .
pecia query "refund policy"
```

`pecia index . --semantic` adds semantic and hybrid search. The [README](https://github.com/eyuppastirmaci/pecia/blob/v0.1.0/README.md) lists the supported files, privacy, disk usage, and known limitations; the [CLI reference](https://github.com/eyuppastirmaci/pecia/blob/v0.1.0/docs/cli.md) covers every option.
