# İade politikası

Müşteriler, teslimattan itibaren 30 gün içinde iade talebinde bulunabilir.

## Para iadesi

Ödeme hangi yöntemle yapıldıysa iade de aynı yönteme yapılır. Kredi kartına yapılan iadeler, ürün depoya ulaşıp
kontrol edildikten sonra beş iş günü içinde müşterinin hesabına yansır.

## Açılmış setler

Ambalajı açılmış kutu setlerde yüzde 15 yeniden stoklama bedeli düşülür. Hasarlı veya yanlış gönderilen ürünlerde
kargo ücreti dahil tutarın tamamı iade edilir.
