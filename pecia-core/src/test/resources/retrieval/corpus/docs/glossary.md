# Glossary

- **Backorder** — an order line accepted while the book is out of stock; it ships when stock arrives.
- **Box set** — several volumes sold as one product with one price.
- **Dispatch** — the moment a parcel leaves the warehouse with a tracking number.
- **Idempotency key** — a client-chosen value that makes a repeated request return the first result instead of
  creating a second order.
- **Outbox** — a table of events written with the business change and published later.
- **PSP** — payment service provider, the company that charges cards for us.
- **Settlement** — the PSP's daily payout and the report listing which charges it contains.
